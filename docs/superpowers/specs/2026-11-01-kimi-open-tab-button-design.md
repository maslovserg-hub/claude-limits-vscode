# Кнопка открытия Kimi Code в новой вкладке — дизайн

Дата: 2026-11-01.

## Цель

Добавить в верхнюю правую панель редактора VS Code значок Kimi, по клику открывающий чат Kimi Code в новой вкладке текущего окна.

## Поведение

- Кнопка использует существующий значок `claude-limits-kimi` и находится в меню `editor/title`, в группе `navigation`.
- Новая команда `claudeLimits.openKimiInTab` вызывает штатную команду расширения Kimi Code `kimi.openInTab`.
- Открывается новая вкладка с чатом; отдельное окно VS Code и новая боковая панель не создаются.
- Если команду Kimi Code выполнить нельзя, пользователь получает сообщение об ошибке с указанием, что требуется установленное расширение Kimi Code.
- Существующие индикаторы лимитов, настройки видимости и команда обновления не меняются.

## Изменения

- `package.json`: зарегистрировать команду `claudeLimits.openKimiInTab`, назначить ей значок Kimi и добавить её в `menus.editor/title`.
- `src/extension.ts`: зарегистрировать обработчик команды, делегирующий открытие вкладки через `vscode.commands.executeCommand('kimi.openInTab')`.
- `README.md`: кратко описать новую кнопку и команду.

## Проверка

- Добавить тест делегирования команды и обработки ошибки, следуя существующей тестовой структуре проекта.
- Выполнить `npm test`, `npm run compile` и `npm run package`.
- Проверить в VS Code: значок виден в верхней правой панели редактора, клик открывает новую вкладку Kimi Code, повторный клик повторяет штатное поведение Kimi Code.

## Границы

- Версию расширения и публикацию релиза в рамках этой задачи не меняем.
- Собственный чат или Webview не реализуем: используется интерфейс установленного Kimi Code.
