При каждом изменении расширения обязательно обновлять оба файла:
1. **CHANGELOG.md** — добавить запись с версией и описанием изменений
2. **README.md** — обновить описание функций, если изменилось поведение

**Why:** Расширением пользуются другие люди, не только владелец. Устаревшее описание вводит в заблуждение. Пользователь прямо потребовал делать это всегда.

**How to apply:** Сразу после правки кода — до упаковки `.vsix` — обновить оба файла. Не ждать, пока попросят.
