**Cloudflare перед `api.anthropic.com` не пропускает запросы, отправленные из Node.js** — на любой путь и с валидным OAuth-токеном возвращается `403 {"type":"forbidden","message":"Request not allowed"}`. Одинаково для `https.get` и `fetch`. Тот же токен через `curl` → `200`. Обнаружено 2026-08-01, когда лимиты Claude в Status Bar замерли на `0% / 0%`.

**Затронуто было три места, не одно:** (1) хук `~/.claude/hooks/save-limits.sh`; (2) собственный опрос расширения раз в 60 сек — `https.get` прямо в `fetchAndRefresh`; (3) тултип с аккаунтом — `fetchAccountLabel` на `/api/oauth/profile`. То есть у **всех пользователей Marketplace** Claude-часть уходила в нули независимо от хука. Плюс расширение при каждой активации безусловно перезаписывало хук своей node-версией — локальная правка файла жила до ближайшего перезапуска VSCode.

**Почему не заметили две недели:** все ошибки молча глотались (`catch {}`, `.on('error')`), старые значения оставались в `limits.json`, и статус-бар уверенно показывал `0%`. Ложные данные выглядели правдоподобнее, чем прочерк. Codex-часть берёт данные из другого источника — продолжала работать и маскировала поломку.

**Как починено (0.3.3):** сетевые вызовы и в расширении, и в шаблоне хука идут через `curl` (в расширении — `curlGet()` на `spawn('curl', ...)`); при неудаче выставляется `claudeFetchError`, статус-бар получает `$(warning)`, а причина (`HTTP 429` и т.п.) уходит в тултип; интервал фонового опроса 60 сек → 5 мин; хук перезаписывается только если его содержимое отличается от шаблона.

**Проверка (критерий успеха):** `bash ~/.claude/hooks/save-limits.sh` → в `~/.claude/limits.json` свежий mtime и ненулевые `used_percentage` с `resets_at`.

**Ещё про эндпоинт:** `/api/oauth/usage` жёстко троттлится. При отладке 2026-08-01 несколько десятков запросов за сессию привели к `429 rate_limit_error`, который держался **около 45 минут** — то есть окно там не только короткое. Поэтому в 0.3.3 хук пропускает запрос, если `limits.json` моложе минуты, а фоновый опрос (раз в 5 мин) — если файл моложе интервала; клик по индикатору обновляет всегда. При отладке не долбить эндпоинт: одна проверка, потом пауза.

**How to apply:** если лимиты снова замерли — сначала руками `curl` к `/api/oauth/usage` с токеном из `~/.claude/.credentials.json`; 403 из node ≠ проблема с токеном. И не писать новые обращения к API Anthropic на node — только curl. [[account-switch-button-abandoned]] [[claude-codex-0.3.2-release]]
