Кнопка «переключить аккаунт» в расширении **окончательно заброшена** (2026-06-03). Эксперимент с кнопкой (версии 0.4.0/0.4.1) откатили — **действующая версия снова 0.3.1** (монитор лимитов + тултип, без кнопки). Больше к этой идее не возвращаться и версию вперёд не бампать.

**Что пробовали (v0.4.0/0.4.1):** подменять `~/.claude/.credentials.json` между двумя сохранёнными аккаунтами. Аккаунт идентифицировали по `account.uuid` из `GET /api/oauth/profile` (в самом файле стабильного id нет — там только `claudeAiOauth` с ротируемыми `accessToken`/`refreshToken`; полей `organizationUuid`/JWT нет). Снимки хранили в `~/.claude-accounts/<account.uuid>.json` + `labels.json` с email.

**Почему невозможно:** Claude Code использует **одну OAuth-сессию на устройство**. Логин во второй аккаунт **отзывает токены первого — и access, и refresh**. Живая проверка: после переключения новый чат показывал экран логина (`How do you want to log in?`), а профиль на сохранённом токене возвращал `401` — хотя по `expiresAt` токен ещё не истёк (значит именно отзыв, не истечение). Восстановить сохранённый снимок без свежего `/login` нельзя → переключение «в одно действие без релогина» принципиально недостижимо.

**Также раньше (v0.3.0→0.3.1):** более ранняя кнопка делала глобальный `claude auth logout` / `claude-vscode.logout` — выкидывала из всех сессий. Тоже откатили.

**Итог:** действующая версия — **0.3.1**, расширение = только монитор лимитов. Живой тултип с аккаунтом (имя + email из `/api/oauth/profile`) оставлен — он безобиден. **Why:** две Pro-подписки ($20+$20), хотелось быстро переключаться при исчерпании лимита. **How to apply:** если снова возникнет запрос на переключение аккаунтов — сразу сказать, что это упёрто в single-session-per-device Anthropic, а не в наш код.
